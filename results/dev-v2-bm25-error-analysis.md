## 4. 机制与三类可复现问题（每条都有上面的数据支撑）

**先看 IDF 机制。** 本项目的 Okapi 实现（`rank_bm25==0.2.2`）根据语料大小 N 和词项文档频率 df 计算原始 IDF：`idf = ln(N - df + 0.5) - ln(df + 0.5)`；当 idf 为负（词项出现在超过一半文档里）时，它被统一替换为 `epsilon × average_idf` 这个地板值。本语料 `N = 6`、`epsilon = 0.25`、`average_idf = 0.8373615299262529`，因此地板 = `0.20934038248156323`。实际结果：

| 词项 | df | 实际 idf | 说明 |
|---|---|---|---|
| 确认 | 6 | 0.20934038248156323 | 原始 idf 为负，压到 epsilon 地板 |
| 检查 | 6 | 0.20934038248156323 | 原始 idf 为负，压到 epsilon 地板 |
| 发现 | 5 | 0.20934038248156323 | 原始 idf 为负，压到 epsilon 地板 |
| 剥离 | 4 | 0.20934038248156323 | 原始 idf 为负，压到 epsilon 地板 |
| 焊线 | 4 | 0.20934038248156323 | 原始 idf 为负，压到 epsilon 地板 |
| 显示 | 3 | 0.0 | df = N/2，原始 idf 恰为 0 |
| oqc | 3 | 0.0 | df = N/2，原始 idf 恰为 0 |
| 记录 | 2 | 0.5877866649021191 | 正向权重 |
| 客户 | 2 | 0.5877866649021191 | 正向权重 |
| 边缘 | 2 | 0.5877866649021191 | 正向权重 |
| prod_001 | 2 | 0.5877866649021191 | 正向权重 |
| 调查 | 1 | 1.2992829841302609 | 最高权重 |
| molding | 1 | 1.2992829841302609 | 最高权重 |
| 塑封 | 1 | 1.2992829841302609 | 最高权重 |
| 空洞 | 1 | 1.2992829841302609 | 最高权重 |
| 锡球 | 1 | 1.2992829841302609 | 最高权重 |
| 托盘 | 1 | 1.2992829841302609 | 最高权重 |
| bga | 1 | 1.2992829841302609 | 最高权重 |

结论：在本语料中，df ≤ 2 的词项具有更高的 IDF，但 **df ≥ 4 的词项仍有正的 IDF，会贡献分数并影响排序**。BM25 的单词贡献还取决于文档词频和长度归一化，不能仅凭 IDF 判断名次。例如只查询 `发现`，C001 得分约 0.3015、C004 约 0.2133，常见词也能产生分差。Q001 的 C001 与 C002 分差来自多个词项，包括 `线脱`、`脱落`、`力检` 等，不能只归因于 `prod_001` / `力检`。`显示`、`oqc` 在本语料的 IDF 为 0，不贡献分数；第 5、6 名的非零得分则来自地板 IDF 词项。这些数值只描述当前 benchmark，语料变化后需重新计算。

**4.1 高频泛词带来缺少症状区分依据的命中。** `确认`、`检查` 在全部 6 篇语料里都出现（df=6），`发现` 出现在 5 篇（df=5），`剥离`、`焊线` 各 4 篇；按上面的机制，它们的权重全部被压到地板值 0.2093，仅凭这些常见词的重合不足以说明症状相关，但它们仍通过词频与长度归一化影响分数。Q001 第 5、6 名就是纯地板词命中：C005 只命中 `oqc, 发现, 检查, 确认`（0.9556），C006 只命中 `发现, 显示, 检查, 确认`（0.7321）。

**4.2 Query 自身的背景句 / 元话语贡献了主要命中词项。** Query 里除了症状描述，还包含"原因尚未确认"（Q001）、"需要查找历史调查记录"（Q002）、"客户收货后发现"（Q003）这类背景话术，它们同样参与词项匹配：

- Q001 的"原因尚未确认"贡献 `确认`（df=6）；"OQC 发现…拉力检查"贡献 `oqc`（df=3）、`发现`（df=5）、`检查`（df=6）。
- Q002 的"需要查找历史调查记录"贡献 `调查`（df=1，只出现在 C002）与 `记录`（df=2，C002 与 C006）。这直接决定了第 2–5 名：C002（1.8190，命中 `发现, 记录, 调查`）高于 C006（0.9051，命中 `发现, 记录`），靠的是只有它含有的 `调查`；C001、C004 只剩 `发现`（0.3015 / 0.2133）。
- Q003 的"客户收货后发现"贡献 `客户`（df=2，C002 与 C006）；它解释了为什么同样只含 `发现` 的 C002（0.6917，额外命中 `客户`）高于 C001 / C004（0.3015 / 0.2133）。

后果：与 Query 症状无关的历史 Case 也能拿到非零分数并被召回，这既造成误召，也直接构成 `precision@3 = 0.5556`、`precision@4 = 0.5`（分母固定为 K 时，召回的不相干 Case 越多，读数越低）。

**4.3 否定语境被当作正面证据命中。** C002 的检索文本包含 Evidence 原句"去除污染后的对照样品润湿改善，**内部焊线检查未发现剥离**"。BM25 是词袋模型，不区分"有剥离"与"未发现剥离"，因此 C002 会与 Q001 的 `焊线`、`剥离` 重合，被抬到第 4 名（1.6463），与同异常站点的 C004（2.4802）差距缩小。这**不代表** C002 的相关性标签有误——它的标签依据是"同产品"（PROD_001），是正确的；问题只在检索侧无法表达否定语义。

**4.4 第 2 名之后的顺序含义很弱。** 第 1 名与第 2 名的分数落差很大（Q002 16.9725 → 1.8190；Q003 20.5476 → 1.2129），第 2 名之后全部落在 0.2133–1.8190，这个量级基本由单个词项的重合决定（多为 `发现` 这类泛词，Q002 第 2 名则靠 df=1 的 `调查`）。因此**不应把第 2 名之后的先后解读为相关性排序**；能可靠解读的只有"第 1 名明显强于其余"。

## 5. 问题 → 可能原因 → 下一步实验

| 问题 | 可能原因 | 下一步实验（M3，M2 不调整口径） |
|---|---|---|
| 泛词（`确认`、`检查`、`发现`）带来误召 | BM25 按 IDF、词频和长度归一化计算贡献，并非所有词项等权；模板泛词在当前语料中仍有正 IDF，可给症状不相关的案例加分 | 停用词表 / 词项加权；或只在异常描述、异常站点等字段上检索（字段权重） |
| 第 2 名之后顺序含义弱 | 该量级只由单个词项重合决定，缺少语义信息 | Embedding 语义检索，以及与 BM25 的 Hybrid 融合对比 |
| 仅同产品的 C002 靠 `prod_001` 加分 | 产品 ID 命中是"同产品即相关"蕴含的正向信号，但也会抬高异常完全不同的记录 | 权重对比实验：产品 / 批次 / 类似产品 / 异常站点字段的权重配比 |
| 否定语境（"未发现剥离"）被计为命中 | BM25 不建模否定与语义方向 | 记为词袋模型的已知局限；Embedding 或结构化字段可部分缓解 |
| 无漏检但 `recall@1 = 0.75` | Q001 有 4 个已确认正例，首位命中 C001，故 Recall@1 为 1/4；Q002、Q003 各为 1，三条等权平均为 0.75。该分母不区分完全相同与仅相关 | 不作为缺陷；若需要 top-1 精确排序，属于 Rerank 实验场景 |

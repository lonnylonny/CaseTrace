## 4. 观察与假设（有证据支撑，但不作结论）

**4.1 Q001 的 C002 为什么会掉下来。** C002 的相关性依据是**同产品** `PROD_001`（与 C001 同产品、同批次、同客户），标签本身没有问题。它的检索文本主体是「引脚润湿不良、焊料未铺展、引脚表面污染/氧化、仓储防潮失效」，与 Q001 的症状词（焊线脱落、焊点剥离）在语义上几乎不重合；文本中唯一直接提到 Q001 症状的是 Evidence 原句「内部焊线检查**未发现剥离**」，而这是一句**否定语境**。

- BM25 把 C002 放在第 4 名，靠的是词袋命中 `prod_001`（df=2，idf 0.5878）与 `焊线` / `剥离`（含那句否定句）。也就是说，**BM25 的"同产品"信号来自产品号被切成了可命中的词项**。
- Embedding 不特殊优待这类产品码字符串，而按整体语义比较，因此 C002 被语义上更"像"的 C006、C005 超过。
- **这是观察与假设，不是已证实的因果**：本轮没有做消融实验（例如只改产品词权重、或去掉否定句再测）。验证方式登记在 M3-06（字段权重 / 否定表达实验），不在本包内执行。

**4.2 Q002 / Q003 的指标相同，但第 2 名之后完全不同。** 两条 Query 只有一个正例、且都排第 1，所以指标看不出差别；但两法的内部顺序几乎没有交集（Q003 的 C004 从第 5 升到第 2，C005 从第 2 掉到第 6）。这说明**当前语料的"第 2 名之后"仍不具备可靠解释力**，与 M2 错误分析第 4.4 条的结论一致。

**4.3 分数分布形状不同。** BM25 的第 1 名与其余差距巨大（Q002 16.97 → 1.82；Q003 20.55 → 1.21），其余落在 0.21–1.82；Embedding 的差距更平缓（Q002 0.7342 → 0.4262；Q003 0.8455 → 0.5451），第 2 名之后集中在 0.34–0.55。**两种方法的分数都不可直接比较**：BM25 无上界且受词频与长度归一化影响，Embedding 是余弦相似度（本语料落在 0.34–0.85）。不得据此说明哪一种"更自信"。

**4.4 否定语境仍然未被处理。** BM25 把「未发现剥离」当成 `剥离` 命中（M2 已记录的局限）。Embedding 虽然编码了整句，但本语料无法证明它理解了否定——它的排名变化来自整段语义，不能当成"语义方法会正确处理否定"的证据。

## 6. 数值复现条件（实测）

| 对照 | 结果 |
|---|---|
| 同一命令连续两次（`--method bm25`） | `benchmark` / `retrieval` / `metrics` / `queries` / `summary` **完全一致**；只有 `generated_at`、`timing.*`，以及 `reproducibility.git_status_paths` 变化 |
| 同一命令连续两次（`--method embedding`，均为 hit） | 同上，五个面板完全一致 |
| Embedding **hit** 与 **miss** 对照 | 排名顺序、逐 Query 指标与全部汇总指标**一致**；分数存在末位浮点差，逐 Query 最大 `|Δscore|` = 2.220e-16 / 1.110e-16 / 3.331e-16 |
| `reproducibility.git_status_paths` | 记录执行时点的工作区状态，可能随文件写入变化；不属于排名或指标差异 |

末位浮点差的成因（已实测确认）：缓存文件保存的是**归一化后的工作矩阵**，其行范数不是精确的 `1.0`（实测 0.9999999999999999 与 1.0000000000000002 各若干行），读取时 `_normalized_matrix` 会再归一化一次，于是末位变化。**这不是缺陷，但必须记录**：`hit` 与 `miss` 不是逐位相同，只有排名与指标相同。因此"缓存只影响耗时不影响结果"这句话只在**排名与指标层面**成立。
